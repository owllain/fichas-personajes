# Kazui Halloween · plantilla independiente

CSS completo `kazui-halloween.css`, clases y animaciones `kzh1-*`, fuentes registradas como KZH1. No importa kazui.css ni el tema Ceniza. Reutiliza únicamente los archivos de fuentes e iconos compartidos, sin cargar sus estilos.

Usa `post-para-foro-halloween.txt` o `post-editable-comentado-halloween.txt`. No mezcles clases ow15 con kzh1. La galería necesita un nombre de grupo único en cada post.

Header: imagen aportada https://i.imgur.com/YeSpBkx.jpeg, servida mediante el proxy de Foroactivo. Para cambiar el encuadre en el div principal: `style="--hw-position:center 10%;--hw-size:cover;"`. Para sustituirla: `--hw-image:url('URL')` en el mismo atributo.

La antigua variante adicional en v15 se conserva para no romper posts que ya la enlacen; esta carpeta es la plantilla independiente a usar en adelante.
