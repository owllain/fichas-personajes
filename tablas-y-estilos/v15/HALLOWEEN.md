# Kazui · Noche de brujas

Morado profundo, naranja calabaza y acentos rojos. Activa `ow15-halloween` junto a `ow15 ow15-nocturne ow15-kazui`, con `kazui-halloween.css`. No combinar con `ow15-ashen`. El CSS importa la base corregida y solo modifica tablas con la clase Halloween. Mantiene los créditos y recursos de v15.

Plantillas: `post-para-foro-halloween.txt` y `post-editable-comentado-halloween.txt`.

La imagen actual es provisional. Para cambiarla, añade al div principal `style="--hw-image:url('URL_DE_LA_IMAGEN');--hw-position:center 10%;--hw-size:cover;"`. No escribir una regla genérica `.ow15-hero`: afectaría otros posts. El tema conserva lectura con scroll, galería por clic y las opciones de movimiento reducido de la base.
